## 스케줄러 기능 개발
워크플로우 빌더로 만든 워크플로우를 스케줄러 기능과 연동하여 설정한 주기에 따라 워크플로우를 실행해주는 기능이다.

### 요구사항
1) 스케줄러는 Spring Quartz를 사용한다.
2) 스케줄러는 com.prometis.appbuilder.scheduler 에서 개발한다.
3) 현재는 개발PC에 작동시키기때문에 1대인데 추 후 서버에 올라가면 여러대가 될수있어 클러스터링을 고려한다. 
   - 설정으로 클러스터링을 할수있어야한다.
4) 스케줄러는 워크플로우ID와 Job을 설정하고 해당 Job이 실행되면 워크플로우ID 기반으로 워크플로우를 실행한다.
5) Job에 여러 워크플로우ID를 설정할수있어야한다.
6) 워크플로우ID 뿐아니라 요청메시지도 Json 형태로 설정할수있어야한다.
7) 웹콘솔에서는 스케줄러 시작/종료, 스케줄러 Job 중지, 시작, 재시작, 트리거, 스케줄러 정보변경, 워크플로우ID 등록 할 수 있어야한다.
8) 스케줄러 웹콘솔은 사이드바에 Scheduler 메뉴를 추가하여 접근한다.
9) 웹콘솔에서는 cron 표기법을 설정할수있고 사용자가 잘 이해하기 쉽게 해당 cron 표기법이 언제 실행되는지도 표기되어야한다.
